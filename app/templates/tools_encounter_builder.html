Calculation reference

Character XP Threshold

The selected difficulty threshold is looked up separately for each party member and then summed. This handles mixed-level parties without averaging.

Variable Party-Size Formula

R = actual party size ÷ baseline party size. Adjusted HP = base HP × R. AC moves approximately ±1 for each ±0.5 shift in R.

Lazy DM Limiting

Average party level below 5 uses one quarter of total party levels. Average level 5 or higher uses one half. This mode is a danger check, not a stat adjustment.
